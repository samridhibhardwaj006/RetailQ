# RetailIQ — Open Retail Intelligence Platform

**Turn retail transaction data into actionable business intelligence.**

RetailIQ is an end-to-end retail analytics platform that transforms transaction-level sales data into meaningful business insights through interactive dashboards, machine learning, customer segmentation, sales trend analysis, and anomaly detection.

It combines a Python-powered analytics backend with a web-based dashboard to help users understand sales performance, identify valuable customer segments, monitor product trends, and investigate unusual transactions.

---

## Overview

Retail businesses generate large volumes of transactional data, but extracting meaningful insights from that data can be challenging.

RetailIQ addresses this problem by providing a centralized analytics platform that converts raw retail transactions into structured KPIs, visual reports, and machine learning-driven insights.

### Key Features

- **Interactive Analytics Dashboard:** Monitor revenue, orders, customers, average order value, and units sold.
- **Customer Segmentation:** Apply RFM analysis and K-Means clustering to identify different customer groups.
- **Sales Trend Analysis:** Visualize monthly revenue patterns and generate baseline trend forecasts.
- **Anomaly Detection:** Use Isolation Forest to identify unusual invoice-level transaction patterns.
- **Product & Market Insights:** Analyze product performance and compare sales across countries.
- **Ask RetailIQ:** Interact with analytics through a rule-based natural-language query interface.
- **Knowledge Desk:** Upload PDF, TXT, and Markdown documents and retrieve relevant information.
- **Data Export:** Export filtered transaction data for further analysis.

## Machine Learning & Analytics

### 1. RFM-Based Customer Segmentation

RetailIQ uses the RFM framework to group customers according to purchasing behaviour.

- **Recency:** Number of days since the customer's last purchase.
- **Frequency:** Number of distinct invoices associated with the customer.
- **Monetary:** Total positive purchase value generated by the customer.

The RFM features are transformed and standardized before applying K-Means clustering.

The resulting customer groups are interpreted using labels such as:

- Champions
- Loyal Customers
- Promising
- Needs Attention

This helps identify customer behaviour patterns and potential retention opportunities.

### 2. Sales Trend Analysis & Forecasting

The platform aggregates sales data into monthly revenue trends.

A linear regression baseline using NumPy's polynomial fitting is used to estimate future revenue trends over a short forecast horizon.

The forecast is intended for exploratory analysis rather than production-grade financial prediction.

### 3. Anomaly Detection

RetailIQ uses the Isolation Forest algorithm to identify unusual invoice-level transaction patterns.

Features include:

- Invoice transaction value
- Total units
- Number of transaction lines

The model identifies potentially unusual transactions for further investigation. An anomaly does not necessarily indicate fraud or an incorrect transaction.

## Data Pipeline

The platform processes retail transaction data through the following stages:

1. Load transaction-level retail data.
2. Convert invoice dates into datetime format.
3. Handle missing values and convert numerical fields.
4. Calculate transaction revenue using quantity and unit price.
5. Identify returns and cancellations.
6. Aggregate transactions into customer, product, country, and monthly-level datasets.
7. Generate KPIs and machine learning features.
8. Serve the processed results through REST API endpoints.

### Dataset

RetailIQ is designed to work with the UCI Online Retail dataset.

The original dataset contains approximately 541,909 transaction records from a UK-based online retailer, covering December 2010 to December 2011.

**Demo data note:** If the original dataset cannot be downloaded, the application uses a labelled synthetic fallback dataset so that the dashboard remains usable. Metrics generated from synthetic data are illustrative and should not be interpreted as actual business performance.

## Getting Started

### Prerequisites

- Python 3.10 or later
- pip
- Git

### 1. Clone the Repository

```bash
git clone https://github.com/samridhibhardwaj006/RetailIQ.git
cd RetailIQ
```

### 2. Create a Virtual Environment

**macOS / Linux**

```bash
python3 -m venv .venv
source .venv/bin/activate
```

**Windows**

```bash
python -m venv .venv
.venv\Scripts\activate
```

### 3. Install Dependencies

```bash
pip install -r requirements.txt
```

### 4. Configure Environment Variables

```bash
cp .env.example .env
```

Add or modify configuration values in `.env` if required.

### 5. Run the Application

```bash
uvicorn app.main:app --reload
```

Open the dashboard:

**http://127.0.0.1:8000**

FastAPI interactive API documentation:

**http://127.0.0.1:8000/docs**

### 6. Run Tests

```bash
python -m pytest -q
```
